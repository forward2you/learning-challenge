# 内容管理小样（阶段02第一步）

2026-09-30。范围：本地 JSON 内容包导入、逐题编辑审核、草稿备份、审核后加入练习。沿用 schemaVersion=1；此次不宣称完成阶段02。

## 验收约定

- 家长入口与儿童答题分离；所有资源本地提供，无网络服务。
- 导入上限2 MiB、1000题；文件结构、页码、年级1—6、版本、重复ID、答案、学习要求必须校验。失败不改变已保存的包。
- 外部包的 approved 不可信：导入后所有题重新成为 draft；修改任何题后重新审核该题。逐题人工核对，不能一键全部审核。
- 草稿可导出；只有每道题审核后才可加入练习。存储失败明确提示，不宣称保存成功。
- 自定义包不能覆盖内置包、内置单元或其他包题目ID；同包更新需要新版本，旧版本保留在本地档案中，成绩仍保留题库版本。当前不合并同单元跨教材内容。
- 导入文字按纯文本展示；恢复存储同样校验，坏存储不阻断内置390题。
- 提供内置包导出以参考格式；新内容必须修改包ID、题ID和单元ID。支持预览不足10题的包，游戏入口不足10题不能开始。

## 边界

知识条目与题目分离、PDF提取/OCR、语音声库、手写、最小安装包和真实手机平板验证仍属于阶段02待办。本轮不调用模型生成题，不联网，不部署。
