# S006 · GitHub Pages 自动校验与部署

日期：2026-09-21。状态：本地实现与验证完成；GitHub 托管部署待执行。

## 范围

为当前纯静态网页增加 GitHub Actions 持续校验与 GitHub Pages 部署。公网页面是可选试玩入口；离线安装包和本地内容包仍是主要交付，本规格不声明多平台发行完成。

## 验收条件

- 拉取请求和 `main` 分支推送运行全部 Node 自动测试，测试失败时不得进入部署。
- 只有 `main` 分支推送或从 `main` 手动触发时部署 Pages；拉取请求不获得部署权限、不更新线上页面。
- 部署使用 GitHub 官方 Pages artifact 和 OIDC 发布流程，权限限制为读取仓库内容、写入 Pages 和签发部署身份令牌。
- 发布 artifact 只含浏览器运行所需文件和 `.nojekyll`，不含 `.git`、测试、规格或验证截图。
- 自动校验 `index.html` 引用的本地脚本、样式和链接均存在，不存在 HTTP(S) 运行资源，资源路径兼容 `/<repository>/` 子路径。
- 工作流显式给出部署环境与页面 URL，并防止同一 Pages 部署并发冲突。
- 本地记录测试与工作流静态校验结果；GitHub 上的真实部署状态和 URL 未实际运行前不得标记通过。
