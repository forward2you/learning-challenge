# S001 · 离线口算挑战规格 v1

状态：已实现，自动测试完成；目标设备及儿童试玩待验收。

## 用户故事

作为三年级孩子，我可以选题型和模式，独立完成10道口算，在答错时得到帮助，结束后看到成绩和错题。

## 功能与验收条件

- AC01：直接打开 index.html，无外部资源和网络请求，可以开始并完成10题。
- AC02：选择三种题库：两至三位数加法；一位数乘除；两位数乘除一位数。每轮不重复题面。
- AC03：加数均为10—999，至少一个达到当前难度的位数；一位数因子1—9；两位数乘数/被除数10—99，另一因子/除数1—9。除法无零除且全部整除。入门加法两位数不进位；进阶两位数可进位；挑战至少一个三位数加数。入门乘除限定较小因子（1—5），进阶/挑战扩大至1—9。
- AC04：点击0—9输入；删除单个数字、清空、提交；物理数字键/退格/Enter可完成同样操作。不接受空答案、非整数、超过4位答案。
- AC05：提交后锁定本题，显示正误和答案，错误提供计算提示；答对停留600毫秒、答错停留1800毫秒后自动进入下一题；第10题自动进入结果。反馈期间禁止输入和重复提交，停留不计答题时间。
- AC06：第10题反馈后显示结果，包括正确数、错题与解析。可同配置再来一轮或返回首页。
- AC07：默认练习无计时压力；挑战显示累计答题时间，反馈页停留不计时。时间仅供自我参考，无排名和淘汰。
- AC08：本地最多保存20轮，首页展示最近一轮；禁用或损坏存储不影响游戏，并说明保存不可用。
- AC09：手机竖屏和电脑可操作，数字面板3列、大按钮、可见焦点、反馈含文字，状态消息辅助技术可读取。
- AC10：每轮生成与整数范围、判分、去重、提示和成绩恢复有自动测试；实机体验另记录。
- AC11：有效JSON中的无效成绩记录被过滤时显示恢复提示；写入失败后本会话仍显示最近结果，并明确刷新后可能丢失，不误报已永久保存。
- AC12：同题重复提交仅计分一次；持续按住Enter不能触发按钮默认重复激活。反馈页不要求点击下一题；数字键不修改答案，退出或重开取消尚未执行的自动跳题。

## 本轮验证实现方式

使用可控时钟及存储替身运行生产应用脚本，验证输入、状态转换、成绩与异常消息；该测试不是移动实机或浏览器布局测试。浏览器另做完整回合、刷新恢复、键盘与窄屏检查。
