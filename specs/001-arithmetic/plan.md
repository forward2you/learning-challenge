# 技术方案

- 零第三方运行依赖，静态 HTML/CSS/JS，可从本地文件运行。
- `src/engine.js`：题目生成、轮次去重、整数判分、计算提示、存储数据清洗；同时支持浏览器全局和 Node 测试。
- `src/app.js`：首页→答题→反馈→结果状态机；仅答题状态接受数字输入；状态转换重绘。
- `src/styles.css`：响应式双栏/单栏、触控数字面板、减弱动效支持。
- localStorage 使用版本化键，仅保存最近20轮汇总；读写均捕获错误，不阻塞玩法。
- 页面不引用远程字体、图片、脚本，不引入 Service Worker；通过下载目录即可离线，不承诺首次访问托管网页后自动可离线。
- Node 内建测试检验题库性质和数据边界；浏览器交互验收单独执行并记录环境。
- 成绩读取封装为可注入存储访问器，分别返回正常、数据已恢复和存储不可访问状态。应用保存失败保持会话内记录并显示准确提示。
- Node VM运行生产app脚本，最小DOM宿主和假时钟用于状态/异常测试；不将其解释为DOM渲染或实机验收。
- 反馈后自动推进：正确600ms、错误1800ms。统一管理推进定时器，首页、重开及结算清理；可控时钟测试实际执行定时回调，验证反馈时间不计入挑战。
