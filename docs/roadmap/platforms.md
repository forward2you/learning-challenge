# 跨平台交付与验证矩阵

## 技术路线（建议，阶段02试验后冻结）

开发与交付约定：开发时使用本机网页版；发布时将同一套网页界面、核心逻辑及本地资源按平台封装为离线应用。阶段02制作最小安装包验证，后续持续回归；用户无需运行开发服务器。详见[分析009](../analysis/009-web-development-offline-packaging.md)。

共用题库格式、题目引擎、游戏规则和界面逻辑；用平台适配层处理文件导入、持久存储、音频、手写和生命周期。交付以离线安装包优先，公网网页/PWA为可选；移动端候选Capacitor，桌面端候选Tauri。选择多种封装会增加维护成本，因此阶段02也比较Tauri统一封装的可行性，以本地语音/手写、包体和设备验证结果决定，不在分析阶段盲目锁定。

- [Capacitor官方文档](https://capacitorjs.com/docs)：提供iOS/Android及Web方向的原生运行时。
- [Tauri架构](https://v2.tauri.app/concept/architecture/)与[分发文档](https://v2.tauri.app/distribute/)：支持主要桌面及移动平台的打包路径。
- [PWA安装说明](https://web.dev/learn/pwa/installation)：浏览器与系统安装方式存在差异，不能将支持网页等同于统一安装体验。

文档只能证明技术路径存在，不能代替本项目实机验收。以上是2026-09-15查询依据。

不购买域名、不租业务服务器。安装包应包含基础题库、语音引擎与声库，禁止首次读题时临时访问外部CDN。扩充与应用升级可由文件包完成。平台首次安装或签名验证所需网络需单独记录，不能和日常离线能力混淆。

## 目标矩阵

| 平台 | 网页验证目标 | 安装形态目标 | 重点验收 |
| --- | --- | --- | --- |
| Windows | Chrome、Edge、Firefox | Windows安装包；支持时PWA | 键盘/鼠标、中文英文朗读、导入导出、升级 |
| macOS | Safari、Chrome、Firefox | macOS安装包；支持时PWA | 音频、文件权限、触控板、迁移 |
| Linux | Chrome/Chromium、Firefox | 明确发行版的安装包 | WebView依赖、字体、语音、发行版兼容 |
| Android手机/平板 | Chrome | Android安装包、PWA | 触控、横竖屏、低内存、后台恢复、手写 |
| iPhone | Safari | iOS应用、添加到主屏幕的网页 | 用户操作后音频播放、锁屏返回、安全区、存储 |
| iPad | Safari | iPad适配的iOS应用、主屏幕网页 | 手指/触控笔、横竖屏、分屏、双人换手 |

最低OS/浏览器版本：阶段02建立实测基线，阶段10冻结，不在无设备证据时填写版本号。浏览器版与安装版分别记录结果。Linux先选择一种明确发行版，不宣称所有发行版。

微信内置浏览器、其他厂商浏览器与鸿蒙浏览器为额外兼容验证对象；微信小程序和纯鸿蒙原生不因网页可运行而自动获得支持。用户未指定这些独立平台，本轮不作发布承诺。

## 三档交付状态

- 核心通过：选题、答题、判分、记录、离线朗读通过。
- 完整通过：核心+图片+手写+双人+棋盘+导入导出通过；输入适配说明明确。
- 未验证/受限：公开列出具体缺项；不能用可打开首页代替功能通过。

目标V1的平台只有“完整通过”才能被列为完整支持。低能力设备可提供受限体验，但不据此把完整验收标为通过。

## 跨平台共同测试

1. 安装/首次加载 → 内容包与声库完整性检查 → 断网 → 关闭后重启 → 完整练习、听写、手写、双人冒险 → 保存 → 再次重启核对。
2. 下载中断、声库缺失、磁盘不足、网页存储被清理：显示真实状态，不崩溃或静默联网，不误报已保存。
3. 导出记录到另一平台导入：档案、题库版本和结果对应；坏文件不能覆盖有效数据。自动同步不在此测试含义内。
4. 升级前后：旧记录迁移、内容修订、音频缓存失效、不兼容版本提示、失败恢复。
5. 输入与展示：窄屏/大屏、横竖屏、系统字号变大、键盘焦点、触屏、触控笔、屏幕阅读器标签。
6. 生命周期：换题取消旧朗读、切后台/锁屏/恢复、双人交接、冒险暂停与结算。
7. 网络观测：所有声库和内容准备就绪后，没有外部推理或语音调用；测试与游戏不自动上传儿童记录。

## 性能预算草案

阶段02在一台明确配置的入门Android、一台iPad和一台桌面设备上试验：普通点击反馈目标100ms内，本地已缓存短语播放启动目标1秒内，未缓存短题合成目标3秒内。达不到时先测量优化、预合成或调整明确支持范围；不得直接删除测试项。模型首次加载单独报告，不能混在热启动指标中。

包体、内存、首次下载和离线存储预算待声库/手写候选实测后冻结，当前不编造容量。首次安装或更新可需要联网，完整安装后日常玩法应离线。
