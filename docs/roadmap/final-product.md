# 最终产品状态与完成定义

这是目标状态，不是当前完成情况。完整V1必须同时满足功能、内容、设备和交付验收，不能因全部页面出现就称已完成。

## 孩子端

1. 选择本地个人档案、年级与已学范围。语数英分别选择教材/学期/单元；昆虫与常识单独选择主题及难度。
2. 五个独立知识入口：语文、数学、英语、昆虫、日常常识。可以自选综合挑战，不强制学科融合。
3. 练习模式：口算、选择、图片判断、古诗字词理解、英语会话、听写补空；错误后有具体解释。
4. 手写模式：根据拼音及语境写汉字、听音和含义补写英文单词；本地识别候选和误识别纠正，保留重写机会。
5. 本地中文/英文朗读：自动读题、重播、停止、语速；听写不显示目标答案；无需用户提交录音或大语言模型。
6. 自我挑战和同设备双人答题；三科进度独立、比赛规则一致。
7. 冒险模式：单人或同设备双人、约十分钟、掷骰子移动、落格答题、答对获得道具、结果结算。
8. 错题复习与进步记录：区分认读、理解、书写/拼写、提示使用；不把骰子运气当作知识能力。

## 家长/内容管理端

1. 在本地导入电子教材（首期明确PDF）、预览提取结果，校正扫描识别、拼音、单元归属和学习要求；也可导入已整理的内容包。
2. 维护语数英教材内容，以及独立昆虫/常识条目；查看来源页码、审核状态和修订记录。
3. 核对候选题、答案、解释和读音后启用。自动提取成功不等于审核通过。
4. 管理多个本地孩子档案、学习范围、声音设置；查看简明练习记录。
5. 导出/导入内容与学习记录备份，检验版本兼容性，升级不丢记录。

PDF解析/OCR采用本地处理或项目离线加工链路；一键自动生成可靠全册题库不是V1承诺。若手机不适合复杂审核，可提供同一产品的桌面管理布局，手机需能导入已审核内容包；界面明确说明各平台可操作范围。

## 内容完成定义

- 建立1—6年级×上下学期×语数英覆盖矩阵，对实际英语起始年级标注“不适用/尚未开始”，不能凭空补教材。
- 每格明确教材版本、单元、发布条目与题型、审核状态。发布前选定具体教材系列；不宣称覆盖所有地区所有版本。当前只有三上三本科目来源，其余资料尚缺。
- 覆盖矩阵内每个承诺单元有经过审核的基础题和支持的题型，必学内容不存在未说明空缺；未完成单元显示状态，不能悄悄用通用题冒充同步内容。
- 昆虫与常识建立主题树、去重机制、来源与复核日期；“大库”分批积累。最终规模在阶段05确定内容目标后冻结，不能以自动生成数量作为质量依据。
- 题型不代表全部学科能力：作文、开放表达和实际口语交流没有被选择题完整覆盖，产品文案要准确。

## 平台完成定义

目标为Windows、macOS、Linux、Android手机/平板、iPhone、iPad上的受支持浏览器；并提供通过验收的桌面和移动安装包。每个平台公布最低实测版本和限制。

主交付为按平台封装同一游戏核心的离线安装包。应用、基础题库、语音引擎和中英文声库随包提供；扩充内容通过本地更新包导入。无需域名、业务服务器或在线账号。首次安装与发行可能涉及平台签名/验证，日常玩法断网可用。本地浏览器入口为可选方案；HTTPS站点和PWA不再是V1完成前置条件。

全平台可用不等于全部设备、内置浏览器、操作系统版本或输入工具都一致支持。微信小程序、纯鸿蒙原生、电视、手表、主机目前不纳入V1承诺，浏览器兼容也需单独测试后才能宣称支持。

## 发布交付

- 版本化源代码、构建指令、题库格式/来源清单、声库及组件清单。
- 通过验收的离线安装包与文件分发渠道、明确支持矩阵、安装与离线使用说明；公网网页地址仅在另行发布网页时提供。
- 内容更新、应用升级、数据迁移和回退方案；发行资源与授权范围核对。
- 不同商店的上架是独立渠道结果：没有实际上架的渠道不写“已上架”；所需开发者账号、签名和提交在发布阶段处理。

## 可选后续能力，不阻塞离线V1

远程好友实时对战、云端账号、跨设备自动同步、公开排行榜、微信小程序、纯鸿蒙原生。这些不是“双人”或“多平台”的自动含义；离线V1的双人先指同一设备轮流，多设备记录通过备份文件迁移。

## 最终退出条件

阶段01—10所需验收完成；支持矩阵每个已承诺平台有实际记录；离线读题、判分、手写与保存无未解决的阻断缺陷；题库审核和覆盖矩阵成立；用户试验重大问题已处理；未完成平台和可选能力明确列出。达到该状态才称“完整V1交付”。
