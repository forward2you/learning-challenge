# PDF教材与知识资料使用说明

2026-09-30 · 规格008

## 使用步骤

1. 刷新学习营地，打开底部「家长 · 内容管理」。
2. 在「教材资料」中选择本地PDF，等待显示原页。最大100 MiB。
3. 输入PDF文件页码，点击「查看此页」，也可以前后翻页。
4. 对照原图检查提取文字。可以只保留本条资料需要的词语、句子或知识点；图片页直接在校对框中录入。
5. 填写学科、年级、学期、教材名称与版本、单元、教材印刷页码和条目标题。PDF页码与教材页脚页码通常不同，不要直接照抄。
6. 点击「保存为待审核资料」。核对完成后点击「已对照原页，审核并保存」。编辑后再次保存会回到待审核。
7. 用「导出知识资料备份」保存JSON。换设备后可以导入，导入项会重新进入待审核状态。

翻页、重新打开文件、刷新或离开前先保存。未点击保存的编辑只在当前表单中，不会自动保留。

## 重新查看已保存条目

在资料列表点击条目可以编辑文字。审核需要同时打开**同一PDF文件的对应页**：先选择原PDF并翻到该页，再选择已保存条目。文件校验值或页码不同会阻止审核，避免错对教材。

系统保存知识文字、原提取文字和文件来源记录，不保存整本PDF。重新查看原图需要再次选择原文件。教材路径不会随资料导出，文件名和SHA256校验值会保留。

## 目前能做与不能做

- PDF有文字层时可提取；扫描图片页只提供预览，尚无图片文字识别（OCR）。少量文字也会提醒人工检查。
- 文字提取可能丢失排版、粗体、音标或顺序，不能据此自动判断教学要求。应以原页为准。
- 知识资料与选择题分开保存，审核知识资料不会自动增加练习题。题库仍使用原有导入审核流程。
- 支持最多500条、知识JSON总计2 MiB，每条文字最多30000字；PDF不计入这个资料容量，因为不会保存整本文件。
- 暂不支持加密PDF。损坏文件不覆盖已保存资料；保存失败会明确提示。
- 开发验证在桌面浏览器进行，file://持久存储、真实Android/iPad、离线安装包未验收。请保留导出备份。
