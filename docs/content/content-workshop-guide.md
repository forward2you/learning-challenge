# 本地内容管理使用说明

2026-09-30 · 阶段02小样

## 第一次试用

1. 刷新学习营地，点击底部「家长 · 内容管理」。
2. 下载「10题示例」，再选择该文件导入。它是第二单元语文题的复习副本，单元名称为「自选复习」。
3. 从题目列表逐题选择，可修改题干、四个选项、答案、解析、学习要求和页码。
4. 对照教材核对后点击「已核对原教材，审核此题」。修改题目会撤销该题审核。
5. 全部审核后点击「加入练习」，看到保存成功提示后返回首页。
6. 选择语文，在单元列表选择「自选复习」。至少10道题才可开始一轮。

管理界面与游戏共用 `index.html` 文件，以减少本地文件页面间存储隔离问题。入口 `content-manager.html` 会转到同一文件的管理区域。

## 保存、备份和更新

- 修改暂存在当前页面，离开或刷新前先导出备份。只有「加入练习」保存成功才写入浏览器。
- 导出的JSON可在其他设备导入；外部文件全部重新审核，不直接信任其审核标记。
- 修改已启用内容时，导入其备份，填写新版本号，再审核并保存。同一个包ID的最新保存版本进入练习，旧版本仍可导出；旧成绩的版本标记保持原样。
- 存储拒绝或空间不足会显示失败。损坏档案恢复时，程序先将原始数据保存在本地恢复项，再写入审核后的题库；恢复项备份失败则取消写入。该项只保留最近一次异常原数据，不代替自己导出的文件备份。
- 更换浏览器、访问地址、移动文件或清除浏览数据，可能无法读取原保存。请保留下载的题库。

## 当前格式与边界

- 题库导入接收JSON题包，最大2 MiB、1—1000题。PDF另在上方「教材资料」区域打开，见[PDF资料说明](pdf-knowledge-guide.md)；不会自动生成题目。
- 目前支持语文/数学/英语的四选一题，年级1—6、学期1或2。界面根据实际导入内容显示年级，不代表已具备全部小学教材。
- 新包不能覆盖内置包，包ID、题目ID和单元ID需避免冲突。示例已具备独立ID，可直接试用；创建多个新范围时需在JSON中配置对应元数据。
- 旧内置第一单元题有些缺PDF页码，可以作为草稿导入，但需补充正确PDF页码才可审核。教材印刷页码与PDF文件页数不是同一个值。
- 不足10题允许编辑、保存；练习仍不能开始。审核按钮表示家长已核对，程序只能校验结构，不能证明答案在教学上正确。
- 本轮未验证真实手机/iPad或file://持久存储，未提供语音或安装包。PDF文字层提取已由下一轮008实现，图片OCR尚未实现。
