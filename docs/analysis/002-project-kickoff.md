# 002 · 项目启动与首版边界

日期：2026-09-15。

## 新指令

用户要求在当前目录创建项目文件夹、每轮分析单独保存文档、采用 spec driven development 开始开发。

## 决定

- 建立独立 `learning-challenge`，不修改同目录已有 `insect-adventure`。
- 先保存原始产品分析，再写第一阶段规格、技术方案、验收与任务。
- 优先交付无需安装依赖、可直接打开的离线网页，原生 HTML/CSS/JavaScript。
- 首版实现全部三组口算范围、每轮10题、屏幕和物理键盘、温和反馈、错题回顾、最近成绩。
- 练习默认不计时；挑战仅记录总时长，反馈停留不计入答题用时，暂不淘汰。
- 第一阶段不加入昆虫奖励关、读题与上传。昆虫建议进入下一轮小范围实验，音频作为后续明确验收的功能。
- 采用经典脚本而非 ES module，保证 `file://` 直接打开时无需服务。

## 待后续验证

教材版本、年级单元对应知识点，目标设备/浏览器，语音方案，手写输入方式，实际孩子使用反馈。当前不声称已完成孩子测试或发布。
