# 006 · 独立知识库与掷骰子冒险模式

日期：2026-09-15。状态：用户需求确认与玩法草案；未开始实现。

## 用户已明确的需求

- 昆虫内容拥有独立知识库，不需要结合语文、数学、英语。
- 日常常识也拥有独立知识库，长期可积累较大内容规模。
- 冒险模式支持单人或双人，一局约十分钟。
- 玩法参考飞行棋：掷骰子、落格答题，答对获得道具。
- 冒险模式不放在第一阶段。

## 对此前分析的修正

分析004中的“校园自然侦探”跨学科融合仅为当时建议，本轮用户明确不需要，后续不以其作为内容建设或玩法的前置条件。历史文档保留，当前产品愿景和本记录优先。

## 内容和玩法分别组织

内容侧包含五个独立分类：语文、数学、英语、昆虫、日常常识。三科按教材版本、年级、学期、单元组织；昆虫和常识按主题、难度、阅读负担组织，不强制绑定教材单元。

独立知识库可以共享题目格式、审核流程和离线朗读组件，不代表必须拆成五套数据库。知识条目与题目实例分开，一个知识条目可以有图片选择、判断、情境选择等题型。每条都保存来源、版本、答案解释和审核状态。

建议昆虫主题：识别、形态、生活史、栖息环境、行为等。常识主题：家庭生活、校园生活、物品使用、公共礼仪、自然天气等。此为组织建议，未开始编题；情境依赖的常识要明确条件，变化较快的内容记录复核时间。“较大知识库”是长期目标，不以未经核对的批量生成题数衡量完成度。

玩法侧包括现有短局练习、后续挑战和棋盘冒险。知识库可以独立进入冒险，不强制混合语数英；是否提供自选混合主题留待规格确认。

## 冒险回合草案（以下为建议，尚非用户定案）

选择知识主题与人数 → 掷骰子 → 棋子移动并落格 → 本地朗读题目 → 作答 → 显示结果 → 答对获得道具 → 可使用道具 → 下一回合。

- 单人：与地图目标或自己的历史表现比较；不默认增加虚拟对手。
- 双人：先考虑同一设备轮流玩，两个独立棋子和道具栏，保持离线；用户未指定必须联网或同屏同时作答。
- 答错：显示简短解析，建议保留本次移动且不发道具，不倒退、不跳过下一回合。此规则尚待试玩。
- 道具：候选为放大镜（排除一个错误选项）、加速鞋（额外前进）、重掷券（重新掷骰）。具体效果、携带上限、使用时机需后续规格定义，避免第一版道具过多。
- 答对获得道具的反馈应明确；不能让道具动画占用大量答题时间。

## 十分钟一局的边界

用户要求一次十分钟。建议以十分钟为目标局长：到时不再开启新轮，完成当前题并结算。双人可完成配对回合以保证回合数相同，因而可能略超时；若以后要求严格600秒，需另定义截断规则，不能同时承诺严格时长和必然等回合。

朗读、动画、思考和轮流等待都会占时间，题数应随实际节奏变化，不能把现有“固定10题”直接等同于“10分钟冒险”。计时从哪里开始、后台或暂停如何处理均需规格化。

胜负候选：按地图进度或目标完成情况结算，正确数用于辅助展示。正式确定前试玩比较。骰子运气与道具会影响结果，因此冒险输赢不能直接当作学科能力评价；学习记录单独保存知识点、是否用提示、作答结果。双人可先选相同难度，未来如支持不同年级则明确为休闲对局。

## 后续spec应回答的问题

1. 地图格数、格子类型、到终点与到时结算规则。
2. 十分钟是目标时长还是硬截止，以及双人最后一轮公平性。
3. 单人目标、双人胜负和平局规则。
4. 道具效果、奖励方式、携带和使用上限。
5. 换手时展示哪些信息，避免后手看到重复题答案。
6. 知识库选择、题目去重、不足时处理、提示对记录的影响。
7. 朗读失败、暂停、退出和重开的行为。

这些细节不阻塞第一阶段，进入冒险阶段时再形成正式spec与验收条件。

## 当前实施边界

本轮只更新需求档案、产品愿景和开发约定。现有口算游戏代码及第一阶段规格不变。冒险、双人棋盘、道具与大规模独立知识库均尚未实现。
