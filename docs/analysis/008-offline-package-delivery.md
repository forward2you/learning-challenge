# 008 · 离线包优先，无需域名和服务器

日期：2026-09-15。用户担心浏览器版需要域名费用与网络，提出采用离线版本包。

## 结论与需求决定

浏览器是运行界面，不必依赖公网网站。现有静态页面可作为本地文件方案候选；localhost/127.0.0.1指向本机，也不需要注册域名。内置浏览器此前阻止file://验证，仍不能把本地文件直接打开记为已通过。

完整产品包含语音、手写、题库与持久记录，更适合交付各平台的离线应用包。调整主路线为“离线安装包＋本地题库/声库更新包”，公网网站/PWA改为可选，不购买域名或租业务服务器。

## 包内应包含

- 游戏界面与规则。
- 基础知识库与图片。
- 离线语音引擎、中英文声库、发音词典。
- 到手写阶段加入本地识别引擎及其资源。
- 内容包导入、备份导出与迁移、离线更新机制。

用户安装后打开应用即可玩，无需手动启动命令行服务器。桌面可按平台封装网页核心；Android用签名APK等发行形态；iPhone/iPad按苹果允许的安装与分发方式处理，不能承诺复制一个压缩包即可永久安装。

## 费用与网络边界

域名费与业务服务器费用不是离线方案的必要成本。不能因此承诺全平台发行零成本：签名、开发者计划、商店分发等按具体渠道核实。安装包获取、平台首次验证或后续更新可能用网络；这些与安装完成后的日常离线使用分开验收。

更新支持传输文件后本地导入，避免启动时强制检查更新或临时下载声音。Windows、macOS、Linux、Android、iOS/iPadOS平台目标保留；各平台是否达到直接文件安装和完全离线首次安装，以实测及发行条件为准。

## 对计划的影响

十阶段功能顺序不变；调整路线总表、最终状态、平台方案和第10阶段交付条件，移除“必须有公网网页地址”的前置条件。当前只更新规划，尚未生成完整安装包，也没有购买域名、注册账号或发布应用。

## 核查依据

- [Android官方发布准备](https://developer.android.com/studio/publish/preparing)：签名APK可直接向用户分发或通过市场分发，具体设备安装条件需核实。
- [Apple开发者会员说明](https://developer.apple.com/support/compare-memberships/)：个人设备测试与正式分发的资格和限制不同，不能将临时开发安装等同长期发行。
