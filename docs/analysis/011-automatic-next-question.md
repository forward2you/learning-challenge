# 011 · 答题后自动进入下一题

用户反馈：每次对错都要点击下一题，操作繁琐。

本轮决定：提交后答对停留600毫秒，答错停留1800毫秒，自动进入下一题；最后一题自动结算。时长为初始交互设定，可根据试玩反馈调整。错题完整解析保留在结果页，不要求孩子在短暂提示中读完。

反馈期间锁定输入，不计入挑战用时。退出或重开取消待执行的跳题，避免旧定时器干扰新一轮；重复提交和长按Enter仍被拦截。

已先更新阶段01规格，再实现。24项自动测试通过，新增/调整自动推进、错误停留、计时排除、退出取消和最后一题只结算一次的验证。浏览器验证正确/错误反馈后自动进入后续题目。Android/iPad实机和儿童试玩仍待执行。
