# 007 · 阶段路线、验证方案与最终状态

日期：2026-09-15。用户要求：规划产品各阶段、生成各阶段验证方案、说明最终状态，并希望各平台可用。

## 本轮交付

建立 `docs/roadmap/`，包含路线总入口、10份阶段计划、最终产品定义、平台矩阵、当前状态、统一验收模板。每阶段明确前置条件、交付、验证方法、通过条件和证据。此为规划工作，未修改游戏代码或执行发布。

## 主要规划决定

- 01口算验收；02内容底座与关键平台试验；03三科单元与读题；04听写补空；05独立昆虫/常识；06综合和双人；07手写；08棋盘冒险；09全小学；10跨平台发布。
- 冒险仍不进入第一阶段，单人/双人、约十分钟、掷骰子落格答题、答对得道具均保留。
- 昆虫与常识独立建库，不要求学科融合；语数英各自选择教材和进度。
- 本地TTS和手写识别先在第二阶段试验，以免发布前才发现目标设备不可用；功能之后分阶段交付。
- 多平台分为浏览器/PWA和安装包两层；目标覆盖Windows、macOS、Linux、Android手机平板、iPhone、iPad。具体版本需要设备证据，封装选型未冻结。
- 微信小程序、纯鸿蒙原生及其他独立平台未被用户具体指定，不自动纳入V1；已有浏览器兼容性也需测试后说明。
- 远程对战和自动云同步不是双人、多平台的必然含义，列为可选后续能力；V1本地档案可用备份文件迁移。
- “最终状态”同时提供目标完成定义与当前实现快照，避免将规划误写成已经交付。
- 全小学内容按选定教材版本的覆盖矩阵验收，不能宣称涵盖所有地区和出版社。当前三上以外教材尚未就绪。

## 验证边界

计划包含内容核对、程序自动化、实机、离线、儿童试玩五类证据。人数、性能与手写识别阈值为本轮提出的试验门槛，正式spec执行前冻结；不是既有研究结论或已达成事实。

阶段01历史12项测试通过和浏览器完整回合记录来自原spec任务文档，本轮未重跑。其他阶段均未验收，不承诺商店审核、发布日期或完整平台已通过。
