# 001 · 产品吸引力分析

日期：2026-09-15。来源：首次产品讨论。本文为分析归档整理版。

## 用户原始设想

产品可发布、跨平台使用，支持上传电子教材，分阶段开发：

1. 离线单机网页口算，每轮10题；两至三位数加法、一位数乘除一位数、两位数乘除一位数；0—9面板及按键提交。
2. 选择年级、单元，使用预先提供的教材，增加古诗和字词；短句、四选一。
3. 从对应年级词语表随机取词，给拼音，手写汉字。
4. 英语常用会话选择，选项带读音。
5. 英语单词听写，提供读音和意思，挖空部分字母供选择。
6. 英语单词手写补空。
7. 以上题型随机混合，综合测试大乱斗。
8. 昆虫侦探：图片题、判断题、选择题。
9. 生活常识问答。

最终体验接近《一站到底》或《非常六加一》的挑战，并支持读题。

## 判断

值得做小版本验证。短局、多样内容和节目式闯关具有潜力，但不能据此保证孩子喜欢。关键是难度合适、答错后的反馈、探索乐趣以及再次主动参与。

推荐定位：面向三年级孩子的知识闯关游戏，每次约5分钟，结合课内练习与课外探索。5分钟是设计目标，需实测，并非强制时长。

| 模块 | 吸引力与风险 | 建议 |
| --- | --- | --- |
| 口算 | 入口清晰，长期重复风险高 | 短局、分层、个人进步 |
| 古诗字词 | 贴近学习，容易像作业 | 情境题、小谜题 |
| 中文手写 | 学习价值明确，识别误判挫败感强 | 平板优先，允许纠错 |
| 英语会话 | 声音与角色互动有潜力 | 生活情境 |
| 字母补空 | 有提示，易进入 | 逐步减少提示 |
| 英语手写 | 适合进阶，输入成本高 | 后期验证 |
| 大乱斗 | 贴合节目体验 | 提前做小规模混合，控制切换 |
| 昆虫侦探 | 有望形成特色 | 图片找线索、图鉴收集 |
| 生活常识 | 增加新鲜感和亲子交流 | 贴近生活，答案明确 |

## 关键建议

- 优先验证一个完整回合：选挑战→答10题→得到具体反馈→看见进步→获得小成果。内容数量不能代替游戏乐趣。
- 难度按知识点拆分：加法是否进位、乘法是否口诀范围、除法是否整除。初期除法全部整除。
- 默认练习不计时，挑战自愿开启；不默认一错淘汰。答错给具体方法提示。
- 区分辨认、提示下补全和独立听写，不能以选择正确推断会独立书写。
- 读题可重播、跳过和关闭；听写不能同时展示答案。计时与播放规则需单独设计。
- 建议早期加入很小的昆虫奖励关，验证课外探索的吸引力；这是建议，尚未纳入第一阶段交付。

## 推荐的验证顺序

1. 口算核心版：验证孩子是否主动再玩一轮。
2. 少量语文、英语会话、昆虫图片与简版混合挑战：验证内容偏好。
3. 教材同步、年级单元、经检查题库、补空和复习：验证学习价值。
4. 中文英文手写与完整综合挑战：验证输入和判分可靠性。

网页跨平台不代表输入体验相同；离线成绩默认仅保存在当前设备。教材应先提取、检查再用于出题。音频和手写需独立验证离线能力。

## 用户验证方案

邀请5—8名熟练程度不同的三年级孩子试玩一周，观察独立开始、主动再玩、隔天主动打开、错误后反应、最喜欢内容；记录是否有家长提醒。小样本用于发现问题，不证明市场需求。用隔日同类新题初步检查学习帮助，将喜欢玩与学会了分开记录。

## 参考依据与局限

- [学校游戏化与参与度研究综述](https://www.frontiersin.org/journals/education/articles/10.3389/feduc.2024.1466926/full)：游戏化可能提升参与度，不能替代具体产品验证。
- [EEF数字学习指南](https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/digital)：技术需服务练习与反馈质量。
- [EEF反馈证据](https://educationendowmentfoundation.org.uk/education-evidence/teaching-learning-toolkit/feedback)：反馈是学习设计中的关键因素。

以上研究并非本产品的三年级用户实验。模块吸引力、5分钟定位与路线调整属于产品假设。
