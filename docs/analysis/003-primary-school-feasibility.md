# 003 · 覆盖整个小学阶段的语数英兴趣与竞赛产品

日期：2026-09-15。状态：产品分析与建议，尚非新功能实施规格。

## 一、本轮用户需求

用户希望产品适合整个小学阶段，帮助孩子对语文、数学、英语建立兴趣，并喜欢答题竞争的环境。用户可以持续提供字词、古诗词、英语词库等内容。

相较前两轮，目标人群从三年级扩大到一至六年级，三年级仍可作为首批验证人群。用户本轮要求继续分析可行性，不代表要求立即实现六个年级的全部内容或联网竞赛。

## 二、结论与定位

技术上可行，用户提供内容能提高教材适配度；真正难点是分龄体验、题库质量、竞争公平性和长期兴趣。尚无本产品的儿童实验、长期留存或付费数据，因此不能断言它一定受欢迎或有商业可行性。

建议定位：覆盖小学一至六年级的语数英知识挑战乐园，按孩子已学内容和能力出题，既能独立探索，也能和熟悉的人公平比赛。

“愿意答题”“喜欢比赛”和“喜欢学科”是三个不同目标。孩子可能为了赢反复做熟悉的题，却不愿学习新内容。需要同时设计发现新知识、获得具体帮助和能力成长的体验。

## 三、分龄与能力

以下是交互设计建议，不是统一课程进度规定。学科内容必须以实际教材、学期和已学单元为准，英语尤其不能假设所有学校从同一年级起步。

| 年级段 | 建议体验 | 竞争方式 |
| --- | --- | --- |
| 一至二年级 | 图片和声音为主、少文字、大按钮、短任务、更多示范 | 和过去的自己比、亲子合作、轮流挑战 |
| 三至四年级 | 情境选择、口算、字词、古诗和英语对话，逐步提高独立性 | 同水平好友挑战、小队合作 |
| 五至六年级 | 阅读线索、推理、多步骤应用、策略题；视觉减少幼儿化 | 同条件限时赛、策略挑战、团体积分 |

同一年级可能存在较大能力差异。年级是筛选入口，已学单元决定可出题范围，近期表现用于练习难度调整。避免仅凭一两道题给孩子贴固定能力标签。

## 四、语数英如何产生兴趣

### 语文

让语言用于理解情境、发现表达和解决谜题。例如从生活场景选择合适词语、按诗句找对应画面、读短文寻找证据。词库能支持多种题型，但听写与选择题不能代表完整的阅读、口语表达和作文能力。

### 数学

口算用于建立熟练度；扩展时增加数量关系、图形观察、规律和生活应用。让孩子选择方法或指出哪里算错，避免始终用答题速度代表数学能力。复杂题目需要独立的时长与评分规则。

### 英语

从问好、借物品、购物等会话情境引入听辨和选择，再进入单词补空与拼写。记录教材对应词义、读音、例句及可接受答案。选对单词不等于能听懂新语境或独立开口表达。

产品初期适合承诺“兴趣引导与基础能力练习”；不能宣传为覆盖三科所有学习目标或替代课堂教学。

## 五、竞争机制

竞争作为可选择的体验，不要求每个孩子都喜欢对抗。目标是让愿意参赛的孩子觉得规则公平，让暂时不想参赛的孩子仍然愿意学习。

建议按以下顺序验证：

1. 自我挑战：同类同难度下比较准确率和表现，避免跨难度直接比较。
2. 离线双人轮流挑战：同设备、等量同条件题目；可采用等难度不同题，但只能称练习性较量，不能声称严格公平。
3. 熟人同题异步赛：固定题集、顺序、提示、读题和时长规则；同题轮流时需考虑后手看过答案的优势。
4. 联网实时赛：独立规划账号、房间、断线、服务端计时计分与结果校验；纯前端分数不可作为公开排行榜可信依据。

比赛原则：正确优先，速度仅作为有限加分或同分比较；题目呈现及读题结束的计时起点一致；提示与重试是否允许需对所有参赛者明确。不能在排名赛中一边给每个孩子不同难度题，一边直接比较原始正确数和速度。

练习可以动态降难、提示、重试；正式比赛必须固定规则。建议不默认全国排行榜、不一错淘汰、不以连败惩罚或连续签到中断惩罚刺激参与。机器人陪练应明确标识，不能伪装真人。

熟人竞争与组队可能比陌生人排名更适合作为早期假设，但尚未由本产品数据验证。

## 六、用户提供内容的价值和加工方式

用户扩充的是本项目的受控内容库，不是直接修改基础模型权重。可离线导入题库，无需每次答题调用大模型。建库过程中可以辅助提取和生成候选题，进入儿童正式题库前必须核对。

建议内容分三层：

- 知识条目：某个字词、古诗、单词、知识点。
- 题目实例：题干、选项、正确答案、解析、媒体及允许答案。
- 出题规则：适用能力、提示层级、难度、前置知识、变式方式。

最小元数据：条目ID、学科、教材出版社/版本、年级、学期、单元、知识点、内容及读音、来源页码、审核状态、内容版本。每题另存题型、答案、解析、难度和对应条目ID。

学科补充字段：

- 字词：拼音、多音字在当前语境下的读音、释义、例句、可接受写法。
- 古诗：标题、作者、原文、分句、注释、教材采用版本；不用生成内容替代原文核对。
- 英语：拼写、教材对应词义、读音音频、例句、大小写及英美拼写接受规则。
- 数学：操作数范围、进退位、整除/余数、单位、前置知识与题目生成约束。

流程：提供教材/列表 → 提取候选条目 → 对照页码核对 → 标注知识点 → 生成候选题 → 检查答案唯一性、干扰项、难度和读音 → 审核 → 打包离线题库 → 记录反馈及修订。未审核内容不可进入排名比赛。

PDF或扫描件可作为来源，后续维护以结构化表格或JSON更方便。只要现有资料，不必要求用户先手动整理六个年级；可以从一册或一个单元共同建立模板。公开发布前，逐项记录教材、音频和图片的来源及可使用范围，不能把个人持有电子书直接等同于可公开分发。

## 七、架构与实施边界

建议长期结构：通用游戏流程 + 分龄界面配置 + 可版本化题库包 + 本地学习记录 + 可选联网竞赛模块。

当前口算实现适合验证基础回合。下一阶段应先规划题库接口和内容版本、年级学期与知识点筛选、通用选择题和反馈、简单能力记录；无需为分析阶段预先实现庞大平台。

离线内容可在导入时更新，做题时不联网。跨设备同步和远程对战是独立联网能力。跨平台仍需验证浏览器、声音、触控与手写，不承诺所有设备体验相同。

## 八、建议验证路线

- 第一步：以三至四年级为首批样本，选用户最容易提供的一册教材中的一个单元，做语数英最小内容闭环；不假设目前已经获得了对应素材。
- 第二步：加入自我挑战、同设备双人或熟人挑战中的一种，比较独立探索和竞赛的体验。
- 第三步：一至二年级及五至六年级分别做小样本验证，再扩内容范围。
- 第四步：有持续主动使用和稳定内容流程后，再投入联网对战、手写及广泛教材适配。

首轮可做约20—30道审核后的选择/情境题每科，加上数学规则生成题。这只是可用性实验规模，不足以验证长期留存。按实际资料与试玩时长调整。

## 九、如何判断有效

从三个维度分别看：

1. 兴趣：无需催促主动打开、主动选不熟悉知识、离开产品后愿意读诗/交流英语/讨论解法。
2. 竞争体验：愿意再赛、输后是否愿意继续、是否只挑弱对手或最简单题、是否认为规则公平。
3. 学习帮助：几天后换同知识点新题仍会做、能否解释答案、提示依赖是否减少。

按年级、初始水平和原本是否喜欢竞争分别观察，不能只看全体平均答题量。早期试玩可先用家长观察表，无需引入在线追踪。探索性小样本不能支持因果或商业结论；付费意愿需另行访谈和真实验证。

## 十、证据与假设边界

- [EEF个别化教学证据](https://educationendowmentfoundation.org.uk/education-evidence/teaching-learning-toolkit/individualised-instruction)：按学习需要提供不同活动和支持可辅助练习与掌握；不等于仅做自动分级就保证有效。
- [EEF反馈证据](https://educationendowmentfoundation.org.uk/education-evidence/teaching-learning-toolkit/feedback)：识别理解缺口和提供可执行帮助是重要设计依据。
- [学校游戏化与参与度综述](https://www.frontiersin.org/journals/education/articles/10.3389/feduc.2024.1466926/full)：游戏化参与效果取决于设计和情境，不能据此保证全年龄段持续喜欢竞争。

分龄表、优先级、竞争形式和内容试验规模均为本轮产品建议。未进行真实孩子试玩、课程全量比对或商业验证。
